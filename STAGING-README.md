# r28 publishing branch

This temporary branch contains the verified r28 archive split into transport chunks and a one-time GitHub Actions publisher. The publisher reconstructs the archive, validates its SHA-256 checksum, preserves the upstream FSL-1.1-MIT license and contribution terms, applies distinct ArchVerse Linux branding, verifies the release, updates `main`, and publishes the `linux-v0.1.33-r28` release.
